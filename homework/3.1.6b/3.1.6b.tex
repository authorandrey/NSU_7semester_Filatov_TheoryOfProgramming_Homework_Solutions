\section*{Задача 3.1.6b}

\textbf{Условие:} Отсортировать через QuickSort последовательность $a_1,\ldots,a_n$ в порядке возрастания элементов.

in: $n,a_1,\ldots,a_n$\\
out: $b_1,\ldots,b_n$, где $b_1\leq\cdots\leq b_n$

\section*{Псевдокод}
Источник: https://gitlab.com/freepascal.org/fpc/source/-/\\
blob/a399f7898cd93a353973f1aa5aadd591ee83c76b/demo/text/qsort.pp\#1
\begin{verbatim}
procedure sort(l, r: longint);
var
    i, j, x, y: longint;
begin
    i := l;
    j := r;
    x := a[(l+r) div 2];
    repeat
        while a[i] < x do
            inc(i);
        while x < a[j] do
            dec(j);
        if not (i > j) then
        begin
            y := a[i];
            a[i] := a[j];
            a[j] := y;
            inc(i);
            j := j - 1;
        end;
    until i > j;
    if l < j then
        sort(l, j);
    if i < r then
        sort(i, r);
end;

begin
    max := len(array);
    sort(1, max);
end;
\end{verbatim}

\section*{Сложность}

До вызова SORT:
\begin{enumerate}
    \item Проверка $n$ и инициализация - $10$ шагов
    \item Чтение массива READ\_ARRAY - $n$ итераций:
    \begin{enumerate}
        \item $3$ шага на проверку конца массива
        \item $5$ шагов на тело цикла
    \end{enumerate}
    \item Последняя проверка конца массива - $3$ шага
    \item Инициализация сортировки и стека INIT\_SORT - $11$ шагов
\end{enumerate}
Значит до вызова SORT время - $8n+24$ шагов.

После сортировки:
\begin{enumerate}
    \item Подготовка PRINT\_INIT - 2 шага
    \item Вывод массива PRINT - $n$ итераций:
    \begin{enumerate}
        \item $3$ шага на проверку конца массива
        \item $5$ шагов на тело цикла
    \end{enumerate}
    \item Последняя проверка конца массива - $3$ шага
    \item Завершение программы - $1$ шаг
\end{enumerate}
Итого, после сортировки время - $8n+6$ шагов.

Значит, общее время вне SORT:
\[
    T_{outside}(n)=16n+30
\]

Стоимость разбиения зависит от массива.
В худшем суммарном случае опорный элемент минимальный. 
Рассмотрим плохое разбиение отрезка длины $m=r-l+1\geq5$, при котором
опорный элемент $x=a[p]$, $p=\lfloor(l+r)/2\rfloor$ минимальный, 
и остаётся правая подзадача длины $m-1$. Пусть $u$ - количество итераций WHILE\_j в первом проходе, $v$ - количество итераций WHILE\_j во втором проходе. Тогда
\[
    u=r-p, v=p-l-1, u+v=m-2
\]

\begin{enumerate}
    \item Инициализация SORT до REPEAT - $13$ шагов
    \item Первый проход через REPEAT, WHILE\_i,
    WHILE\_j: 
    \begin{enumerate}
        \item Переход и проверка WHILE\_i - $1+5$ шагов
        \item WHILE\_j - $u$ итераций по $11$ шагов и завершающая проверка
        на опорном элементе - $7$ шагов
        \item IF\_not\_i\_gt\_j - $3$ шага, обмен и изменение $i,j$ - $22$ шага
        \item UNTIL - проверка и переход к следующему проходу - $4$ шага
        \item Итого:
        \[
        1+5+11u+7+3+22+4=11u+42
        \]
    \end{enumerate}
    \item Второй проход через REPEAT, WHILE\_i,
    WHILE\_j:
    \begin{enumerate}
        \item Переход и проверка WHILE\_i - $1+5$ шагов
        \item WHILE\_j - $v$ итераций по $11$ шагов и завершающая проверка
        - $7$ шагов
        \item В IF\_not\_i\_gt\_j - $3$ шага
        \item UNTIL - $3$ шага
        \item IF\_l\_lt\_j и IF\_i\_lt\_r - по $4$
        шага
        \item Итого:
        \[
        1+5+11v+7+3+3+4+4=11v+27
        \]
    \end{enumerate}
    \item От IF\_i\_lt\_r до Jump SORT - $18$ шагов
\end{enumerate}

Значит от входа в SORT до вызова правой подзадачи:
\[
    T_{sort}(m)
    =13+(11u+42)+(11v+27)+18
    =13+11(m-2)+69+18
    =11m+78
\]

После завершения рекурсивного вызова
$cs=2$. CALL\_STACK\_RETURN - $17$ шагов. 
Значит
\[
    T_{call}(m)=11m+78+17=11m+95
\]

Для отрезка длины $4$ рассмотрим массив $[4,3,2,1]$. Опорный элемент
$x=a_2=3$. После двух обменов получаются подзадачи $[1,2]$ и $[3,4]$.

Сначала посчитаем затраты одной подзадачи длины $2$:
\begin{enumerate}
    \item Инициализация в SORT - $13$ шагов
    \item От REPEAT до UNTIL:
    \begin{itemize}
        \item REPEAT - $1$ шаг
        \item проверка WHILE\_i - $6$ шагов
        \item в WHILE\_j первая проверка - $7$ шагов, уменьшение $j$ - $4$ шага,
        повторная проверка - $7$ шагов, всего $18$ шагов
        \item проверка IF\_not\_i\_gt\_j и обмен - $3+22$ шага
        \item завершающая проверка UNTIL - $3$ шага
    \end{itemize}
    Итого разбиение: $1+6+18+3+22+3=53$ шага
    \item Проверка IF\_l\_lt\_j: переход выполняется после $3$ шагов
    \item Проверка IF\_i\_lt\_r - $4$ шага
\end{enumerate}
Значит, одна подзадача длины $2$ занимает
\[
    13+53+3+4=73
\]
шага без учета возврата.

\begin{enumerate}
    \item Инициализация в SORT - $13$ шагов
    \item Разбиение от REPEAT до выхода через UNTIL:
    \begin{itemize}
        \item первый проход: REPEAT - $1$ шаг, WHILE\_i - $5$ шагов
        WHILE\_j - $6$ шагов, проверка IF\_not\_i\_gt\_j и обмен - $3+22$ шага,
        UNTIL с переходом к повтору - $4$ шага
        \item второй проход: REPEAT - $1$ шаг, WHILE\_i - $6$ шагов;
        WHILE\_j - $6$ шагов, проверка IF\_not\_i\_gt\_j и обмен - $3+22$ шага,
        UNTIL - $3$ шага
    \end{itemize}
    Итого разбиение:
    \[
        1+5+6+3+22+4+1+6+6+3+22+3=82
    \]
    \item Проверка IF\_l\_lt\_j - $4$ шага
    \item Левый вызов: подготовка стека до Jump SORT - $11$ шагов,
    SORT для подзадачи - $73$ шага,
    возврат с $cs=1$ в CALL\_STACK\_RETURN - $16$ шагов
    \item После возврата проверка IF\_i\_lt\_r - $4$ шага
    \item Правый вызов: подготовка стека до Jump SORT - $18$ шагов,
    SORT для подзадачи - $73$ шага,
    возврат с $cs=2$ в CALL\_STACK\_RETURN - $17$ шагов
\end{enumerate}
Финальная обработка возврата главного вызова - $2$ шага.
Значит:
\[
    T_{SORT, body}(4)=13+82+4+(11+73+16)+4+(18+73+17)+2=313
\]

Значит для $n\geq4$:
\[
T(n)
=311+\sum_{m=5}^{n}(11m+95)+2
=\frac{11n^2+201n-354}{2}
\]

Для малых входов экспериментально программа даёт:
\[
T(1)=109,
T(2)=137,
T(3)=262
\]
- тут уже с учетом outside.

И если добавить $T_{outside}(n)=16n+30$, то получаем:
\[
T_{\max}(n)=
\begin{cases}
109, & n=1\\
137, & n=2\\
262, & n=3\\
\dfrac{11n^2+233n-294}{2}, & n\geq 4
\end{cases}
\]
