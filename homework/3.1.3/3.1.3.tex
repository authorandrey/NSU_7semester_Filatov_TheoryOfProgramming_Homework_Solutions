\section*{Задача 3.1.3}

\textbf{Условие:} Определить, является ли последовательность \(a_1, \dots, a_n\) палиндромом. Вывести 1, если является, или 0, если не является (1 балл):\\
in: n, a1, ..., an \\
out: r in \{0,1\}

\section*{Решение}

\begin{verbatim}
Read 1  ; n

Load =0
Sub 1
JGTZ SUCCESS    ; n < 0
JZero SUCCESS   ; n == 0

Load =3
Store 2     ; buf starts at r3
Load 1
Add =3
Store 1     ; buf ends at r{n+3} (not including last)
FILL_LOOP: Load 1
    Sub 2
    JZero END_FILL
    Read *2 ; r{3+index} <- input
    Load 2
    Add =1
    Store 2 ; inc r2
    Jump FILL_LOOP
END_FILL: Load =3
    Store 2     ; restart start pointer
    Load 1
    Sub =1
    Store 1     ; last element of buf is at r{n+3-1}
CHECK_LOOP: Load 2
    Sub 1
    JZero SUCCESS
    JGTZ SUCCESS
    Load *1
    Sub *2
    JZero MOVE_INDEXES
    Jump FAIL
MOVE_INDEXES: Load 1
    Sub =1
    Store 1
    Load 2
    Add =1
    Store 2
    Jump CHECK_LOOP
SUCCESS: Write =1
    Halt 0
FAIL: Write =0
    Halt 0
\end{verbatim}

\section*{Сложность}

Худшим случаем является палиндром, так как тогда нужно проводить все сравнения.

\begin{enumerate}
    \item До FILL\_LOOP инициализация за 10 шагов
    \item Цикл FILL\_LOOP выполняется n раз
    \item Одна итерация занимает 8 шагов
    \item На последнюю проверку условия 3 шага
    \item END\_FILL занимает 5 шагов
    \item CHECK\_LOOP выполняется $\lfloor n/2 \rfloor$ раз
    \item Каждая проверка занимает 14 шагов
    
    Количество шагов на последнюю проверку:
    \begin{itemize}
        \item Если n чётное, то на последнем шаге срабатывает JGTZ SUCCESS - 4 шага. Общее время цикла: $7n + 4$ шага
        \item Если n нечётное, то на последнем шаге срабатывает JZero SUCCESS - 3 шага. Общее время цикла: $7n - 4$ шага
    \end{itemize}
    
    \item SUCCESS занимает 2 шага
\end{enumerate}

Итоговая сложность в худшем случае:

Для чётного \(n\):
\[
    T_{\max} = 10 + (8n + 3) + 5 + (7n + 4) + 2 = 15n + 24
\]

Для нечётного \(n\):
\[
    T_{\max} = 10 + (8n + 3) + 5 + (7n - 4) + 2 = 15n + 16
\]
