# Отчёт о проверке

## Что удалось проверить в текущей среде

- Чистые TypeScript-модули модели и алгоритмов скомпилированы командой `tsc` в строгом режиме (`--strict`).
- Проведены ручные исполнения алгоритмов симуляции, минимизации Хопкрофта, табличной минимизации, произведения, проверки эквивалентности, Union-Find и детерминизации.
- Выполнены проверочные сравнения языка до и после минимизации и детерминизации для всех слов до фиксированной небольшой длины.
- Дополнительно выполнено 75 случайных тестов минимизации с проверкой сохранения языка и эквивалентности результата, а также 50 случайных пар автоматов для сравнения результатов проверок эквивалентности через произведение и Union-Find.
- Исходники UI проверены на синтаксическую и базовую структурную согласованность с временными объявлениями типов для отсутствующих npm-пакетов.

## Что не удалось проверить

Полная установка зависимостей не состоялась: среда не смогла разрешить `registry.npmjs.org` (`EAI_AGAIN`). Поэтому здесь нельзя честно утверждать, что успешно прошли настоящие `npm install`, `npm test`, `npm run build` или запуск интерфейса в браузере. После распаковки проекта в среде с доступом к npm выполните команды из README.

## Известные области риска для последующей проверки

- Реальные типы текущей версии Cytoscape.js и поведение compound-узлов («облачков») должны быть проверены после установки зависимостей и запуска браузера.
- PDF генерирует растровые страницы высокого разрешения, чтобы избежать потери кириллицы. Нужно визуально проверить размер текста и сложные таблицы в PDF.
- Автораскладка графов является эвристической; для сложных графов может потребоваться вручную раздвинуть вершины перед экспортом.
