# Архитектура проекта

```text
src/model       типы автомата, валидация, переходы, достижимость, парсер
src/trace       структуры шагов алгоритмов и результата
src/algorithms  чистые функции вычислений и построение трасс
src/components  React UI, редактор, управление шагами, граф Cytoscape
src/export      SVG, растрово-векторный PDF, JSON
src/__tests__   unit/property-based по небольшим конечным пространствам
```

## Поток данных

1. `App` хранит два автомата A и B, текущий режим и трассу.
2. Пользователь запускает выбранный алгоритм.
3. Алгоритм создаёт `Trace` с упорядоченными снимками состояний вычисления.
4. Выбор индекса шага переключает видимый снимок. Граф и таблицы берут данные из того же `Step`.
5. Экспорт использует ту же трассу и снимает вид графа для ключевых либо всех шагов.

## Принципы

- Вычислительные модули не импортируют React/Cytoscape.
- Каждый шаг хранит снимок автомата; компоненты не запускают алгоритм повторно.
- Классы эквивалентности — множества состояний в данных, а облачка — только их визуальное представление.
- Имена состояний и позиции графа отделены от вычислительной логики.
- Обрабатываются ошибки неполных/недетерминированных входов; алгоритмы не должны молча подменять математическую модель.
