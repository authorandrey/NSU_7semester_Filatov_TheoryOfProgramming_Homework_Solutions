## Модель

Автомат задаётся кортежем с алфавитом, конечным множеством состояний, начальным состоянием, множеством заключительных состояний и переходами. Внутри приложения переходы хранятся списком записей `from/symbol/to`; ε-переходы хранятся отдельно.

Для словесной симуляции в текущей версии каждый символ алфавита — один Unicode-символ. Это соответствует стандартным примерам курса над алфавитами `{a,b}`, `{0,1}` и подобными.

## Минимизация

Реализован алгоритм Хопкрофта:
1. Проверка детерминированности.
2. При необходимости — дополнение незаключительным стоковым состоянием.
3. Поиск и, если включена настройка, удаление недостижимых состояний.
4. Начальное разбиение заключительных и незаключительных состояний.
5. Обработка блоков-разделителей и символов алфавита.
6. Вычисление прообраза `X = {q | δ(q,a) ∈ A}`.
7. Расщепление блоков, которые пересекаются с `X` не полностью.
8. Обновление рабочей очереди; при разделении блока, которого нет в очереди, добавляется меньшая часть.
9. Построение фактор-автомата.

Каждый шаг сохраняет снимок автомата и текущее разбиение для визуализации.

## Табличный метод

Это дополнительный метод. Пары состояний сначала отмечаются, если одно состояние заключительное, а другое — нет; далее маркируются пары, ведущие по символу в уже различимую пару. После стабилизации непомеченные пары группируются в классы. Этот алгоритм тестируется отдельно, но не заявляется как алгоритм, непосредственно предписанный семинарским листом.

## Произведение

В режимах пересечения, объединения и симметрической разности состояние результата — пара состояний. Переход по символу выполняется покомпонентно. Заключительность пары определяется выбранным режимом. Строятся достижимые пары от начальной пары; недостижимые пары полного декартова произведения не добавляются.

## Эквивалентность

Метод через произведение исследует достижимые пары по BFS и использует симметрическую разность: пара заключительная тогда и только тогда, когда заключительность компонентов различается. При обнаружении такой пары восстанавливается кратчайшее различающее слово.

Метод Union-Find начинает с пары начальных состояний, использует операции `Find`/`Union` и добавляет пары соответствующих переходов. Если один класс содержит как заключительное, так и незаключительное состояние, автоматы неэквивалентны.

## НКА и ε-переходы

Симуляция НКА хранит множество активных состояний. Для ε-НКА применяется ε-замыкание. Детерминизация использует метод подмножеств; пустое подмножество включается, если оно достижимо, и становится стоком.

## Визуализация

- Текущие состояния, конфликтные состояния, новые состояния и переходы выделяются разными цветами и толщиной обводки.
- Классы разбиения отображаются как compound-группы Cytoscape («облачка»).
- Каждый шаг алгоритма содержит описание операции, снимок автомата и доступные таблицы.
- Экспорт SVG отображает облачка классов; PDF строится по выбранным шагам с графом, пояснениями и таблицами.
