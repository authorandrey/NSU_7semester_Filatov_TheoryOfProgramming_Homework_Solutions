Задача validate_number

Параметры
- m — основание системы счисления, 2 ≤ m ≤ 36.
- orientation — соглашение о порядке цифр:
  - right: младший разряд справа, как в обычной записи числа;
  - left: младший разряд слева.

Представление цифр
- Значения от 0 до 9 записываются символами 0–9.
- Значения от 10 до 35 записываются буквами A–Z.
- В алфавит машины включаются только символ # и цифры со значениями от 0 до m−1.
- Для любого другого символа переход не создаётся. Если такой символ встретится во входе, эмулятор автоматически завершит работу с ERROR.

Соглашение о корректной записи
- Число должно содержать хотя бы одну цифру.
- Ноль записывается только как 0.
- У многозначного числа старший разряд не может быть равен 0.
- Корректная запись остаётся неизменной, машина останавливается в STOP.
- Некорректная запись приводит к ERROR.

Алгоритм при orientation = right
1. Перейти от левого разделителя # к первому символу строки.
2. Если сразу встретился #, строка пустая: перейти в ERROR.
3. Если первый символ — 0, проверить следующий символ:
   - если это #, строка равна 0: перейти в STOP;
   - если это допустимая цифра, запись имеет лишний ведущий ноль: перейти в ERROR.
4. Если первый символ — цифра от 1 до m−1, просматривать остальные символы справа:
   - на каждой цифре из допустимого алфавита продолжать просмотр;
   - на правом разделителе # перейти в STOP.
5. На символах вне допустимого алфавита переходов нет; эмулятор сам выдаёт ERROR.

Алгоритм при orientation = left
1. Перейти от левого разделителя # к первому символу строки.
2. Просматривать строку вправо:
   - на каждой цифре из допустимого алфавита продолжать просмотр;
   - на правом разделителе # сдвинуться на одну позицию влево и проверить старший разряд.
3. Если при проверке старшего разряда встретился #, строка пуста: перейти в ERROR.
4. Если старший разряд не равен 0, запись корректна: перейти в STOP.
5. Если старший разряд равен 0, посмотреть на предыдущую позицию:
   - если там левый разделитель #, вход — единственный символ 0: перейти в STOP;
   - если там цифра, запись содержит лишний старший ноль: перейти в ERROR.
6. На символах вне допустимого алфавита переходов нет; эмулятор сам выдаёт ERROR.

Обозначение D_m = {0, 1, ..., m−1}. Генератор добавляет команды только для цифр из D_m и не генерирует явные переходы для посторонних символов.
