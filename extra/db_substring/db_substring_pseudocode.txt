Задача: дана фиксированная строка db над {a,b}; входное слово w также над {a,b}.
Проверить, является ли w подстрокой db.

Выходное соглашение:
- если w является подстрокой db, машина стирает w и останавливается в STOP;
- иначе машина переходит в ERROR.
- пустое слово считается подстрокой любой строки и принимается.

Идея: построить автомат по множеству всех подстрок db.

1. Создать множество S, состоящее из пустого слова и всех непустых подстрок db.
2. Для каждого p из S создать состояние PREFIX_p. PREFIX_EMPTY соответствует пустому уже прочитанному префиксу входа.
3. Из START на левом # перейти вправо в PREFIX_EMPTY.
4. В состоянии PREFIX_p:
   - если прочитан #, входное слово закончилось. Поскольку p — подстрока db, принять и остановиться;
   - если прочитан символ c из {a,b} и p+c принадлежит S, стереть c (записать #), перейти вправо в PREFIX_(p+c);
   - если p+c не принадлежит S, перейти в ERROR.
5. Все символы входа стираются по мере чтения. Поэтому при принятии лента пуста; в формате тестов эмулятора пустая лента записывается как #.

Почему достаточно помнить всё прочитанное слово p: после каждого входного символа машина проверяет, принадлежит ли накопленный префикс множеству подстрок db. Если на некотором шаге p+c не является подстрокой db, никакое продолжение уже не сделает весь вход подстрокой db, поэтому можно сразу завершить работу в ERROR.

Генератор создаёт по одному состоянию для каждой различной подстроки db, включая пустую строку. Переходы упорядочиваются по длине строки, затем лексикографически.
