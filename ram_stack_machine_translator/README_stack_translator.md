# Транслятор стека для RAM

Скрипт `ram_stack_translator.py` раскрывает псевдоинструкции `push` и `pop` в обычные инструкции RAM и сохраняет результат в `.asm`.

## Соглашения

В семинаре 6 задача формулируется так: читать целые числа до `0`, затем вывести их в обратном порядке, используя `push` и `pop`. Способ реализации стека в тексте задания не фиксируется, поэтому транслятор использует такие соглашения:

- `push OPERAND` кладёт значение операнда на стек.
- `pop DEST` снимает верхний элемент и записывает его в `DEST`.
- `push` принимает `=C`, `A` или `*A`; `pop` принимает `A` или `*A`.
- `B` — адрес первой ячейки стека; указатель стека хранится в `M[B-1]`.
- Указатель хранит адрес следующей свободной ячейки. Стек растёт к большим адресам; пустой стек означает `SP=B`.
- Ячейка `B-1` и ячейки от `B` вверх зарезервированы под стек. Они не должны пересекаться с памятью программы.
- `pop` из пустого стека не проверяется: программа обязана не допускать этого.

## Во что раскрываются команды

Пусть `SP_CELL = B-1`.

### `push OPERAND`

```asm
Load OPERAND
Store *SP_CELL
Load SP_CELL
Add =1
Store SP_CELL
```

Значение записывается в `M[M[SP_CELL]]`, после чего указатель увеличивается.

Например, при `B=10000` (`SP_CELL=9999`):

```asm
push 7
```

раскрывается в:

```asm
Load 7
Store *9999
Load 9999
Add =1
Store 9999
```

### `pop DEST`

```asm
Load SP_CELL
Sub =1
Store SP_CELL
Load *SP_CELL
Store DEST
```

Указатель сначала уменьшается, затем считывается верхний элемент.

При `B=10000`:

```asm
pop 3
```

раскрывается в:

```asm
Load 9999
Sub =1
Store 9999
Load *9999
Store 3
```

## Использование

```bash
python ram_stack_translator.py program.ram_stack
```

По умолчанию создаётся `program.asm` рядом с исходным файлом.

```bash
python ram_stack_translator.py program.ram_stack -o build/program.asm
python ram_stack_translator.py program.ram_stack --stack-base 10000
```

`--stack-base` задаёт адрес первой ячейки стека. По умолчанию выбирается адрес не ниже `10000` с запасом относительно числовых литералов. Это эвристика: при динамической адресации нужно самостоятельно убедиться, что память не пересекается.

## Пример

Файл `examples/reverse.ram_stack` читает числа до нуля, кладёт их в стек, затем извлекает и печатает в обратном порядке. Ноль служит признаком конца и в стек не попадает. Файл `examples/reverse.asm` содержит результат трансляции при `--stack-base 10000`.

Транслятор также перенумеровывает числовые адреса переходов `Jump`, `JZero`, `JGTZ`, чтобы раскрытие псевдоинструкций не изменило смысл переходов. Метки и комментарии `;` поддерживаются. В выходном файле нет `push` и `pop`.
